# NERO - Digital Creative Studio Portfolio

A stunning, interactive portfolio website showcasing digital creative work with modern UI/UX design.

## ✨ Features

- **Interactive Hero Section** with particle text effect
- **3D Card Stack** showcase with smooth fan animations
- **Custom Cursor** with follower effect
- **Smooth Animations** with scroll reveals
- **Fully Responsive** design for all devices
- **Dark Theme** with orange accent colors

## 🚀 Tech Stack

- Pure HTML5
- Vanilla CSS3 (with CSS custom properties)
- Vanilla JavaScript (ES6+)
- No frameworks or dependencies!

## 📂 Project Structure

```
portfolionero/
├── index.html          # Main HTML file
├── style.css           # All styles and animations
├── script.js           # Interactive functionality
└── README.md          # This file
```

## 🎨 Key Sections

1. **Hero** - Animated title with particle background
2. **Particle Typography** - Interactive "NERO" text effect
3. **Projects** - 3D card stack with 7 portfolio items
4. **About** - Studio information and statistics
5. **Process** - 4-step workflow showcase
6. **Contact** - Form with glassmorphism design

## 🖥️ Running Locally

Simply open `index.html` in your browser. No build process needed!

```bash
# Option 1: Double-click index.html

# Option 2: Use Python's built-in server
python -m http.server 8000

# Option 3: Use Node's http-server
npx http-server
```

Then visit: `http://localhost:8000`
